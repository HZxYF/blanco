About this site

I have loved Real Madrid since I was young, so I want to introduce this club to everyone by telling its history and passing on the spirit of Real Madrid

Sources

Every date, score and venue was checked against the Wikipedia articles on Real Madrid and on the list of European Cup and Champions League finals. Where those sources disagreed with what I thought I knew, the site follows them, not me. The 2024 final is the cut-off: nothing after it is described.

How it is built

Five HTML pages, one CSS file, one JavaScript file of about forty lines. No framework, no build step, no database, no server-side code. Every page is a complete document that works on its own, which is why the site survives being opened straight from a folder as well as from the web.

The filter on the finals page is an enhancement, not a requirement: with JavaScript turned off, all fifteen finals are still visible and the table still reads. That was a deliberate choice — a page that breaks without script is a page that fails on a bad connection.

Decisions worth explaining

  • Serif text, one column, about seventy characters wide. This is a reading site. Long lines are hard to track, so the measure is capped and the layout does not expand on a large screen.
  • Buttons, not a dropdown, for the decade filter. All the options are visible at once, and each is a real button that works with a keyboard.
  • Wide tables scroll sideways instead of shrinking. On a phone the finals table keeps its text size and slides; the alternative was unreadable columns.
  • No photographs. A history site does not need them, and I did not want to fill it with pictures I have no right to use.

Corrections

If a fact here is wrong, I would rather know. Open an issue on the repository and say which line it is; the source code is the same thing you are reading.
